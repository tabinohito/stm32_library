# Board integrations

This directory contains opt-in, board-specific composition code. It is not
included by `stm32_peripherals.hpp` or `stm32_modules.hpp`, so the reusable
peripheral and module layers remain independent of any application framework.

`prindog/` binds the STM32F765 hardware generated by STM32CubeMX to the
`realtime_bridge_interface` interfaces. A project using this board integration
must add both `stm32_library` and `realtime_bridge_interface` to its include
path. Projects that only use `stm32_library` do not need
`realtime_bridge_interface`.
